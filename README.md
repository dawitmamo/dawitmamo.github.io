# Dawit Mamo — Freelance Portfolio

A responsive, light-theme portfolio website for GitHub Pages. The site emphasizes freelance services, selected project areas, technical skills, and clear contact links.

## Files

- `index.html` — portfolio content and structure
- `styles.css` — responsive light-theme styling
- `script.js` — mobile navigation and current year
- `.nojekyll` — optional GitHub Pages helper

## Before publishing

1. `dawit.JPG` is used as the profile photo in the hero section.
2. `Dawit_mamo_cv (1).pdf` is linked from the navigation, hero, and About section.
3. Verify project details and replace general GitHub profile links with specific repository links or case studies.
4. Make sure each listed skill reflects work you can confidently discuss.
5. Check the email and LinkedIn links.

## Publish as a personal GitHub Pages site

1. Sign in to [GitHub](https://github.com/) as `dawitmamo`.
2. Create a **public** repository named exactly `dawitmamo.github.io`.
3. Upload `index.html`, `styles.css`, `script.js`, `.nojekyll`, and `README.md` to the repository's root (not inside an extra folder).
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes and visit **https://dawitmamo.github.io/**. If it does not load immediately, check the Pages status and Actions tab.

## Update the live site

Edit a file locally, then commit and push the changes to the `main` branch. GitHub Pages republishes the site automatically.

No build command, package manager, or server is required.
